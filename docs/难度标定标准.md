# 难度标定标准

题库用三档难度：**基础（绿）· 提高（黄）· 挑战（红）**。一道题的难度由「推理步数 → 技巧性 → 知识面」三个维度依次判定，冲突时取最高档。

---

## 一、三档定义

### 基础（D1，绿）

满足以下任一条：

- 直接套用一个公式、定义或定理，**一步**完成计算；
- 或默写 / 辨认定义、定理、性质的表述（不做推理）。

> 例：`lim (2n+1)/(3n+5)`（同次取系数比）、`(sin x)'`、`∫x dx`、二阶行列式直接展开、单位矩阵的秩、罗尔定理的结论、A·I=A。

### 提高（D2，黄）

满足以下任一条：

- 需要**一次判断或辨析**：充要条件、性质是否适用、可导性、敛散性、线性相关/无关；
- 需要**一次方法选择**：等价无穷小、洛必达、行列式展开、初等行变换、消元法；
- 或 **2–3 步连贯计算**。

> 例：`lim (1−cos x)/x²`（选等价无穷小）、`|x|` 在 0 处的可导性（判断）、三阶行列式展开、齐次方程组自由变量个数、`A²` 的某个元素。

### 挑战（D3，红）

满足以下任一条：

- 需要**构造性技巧**：有理化、取对数、降幂、凑标准极限 / 标准形；
- 或 **3 步以上**且中间任一步容易出错；
- 或**结论非常规**（需记忆特殊结果，如 Σ1/n² = π²/6）；
- 或**综合两个以上知识点**。

> 例：`lim(√(n+1)−√n)·√n`（有理化）、`xˣ` 的导数（取对数）、`∫₀^{π/2} sin²x dx`（降幂）、`Σ1/n²`（π²/6）、`lim ⁿ√n`（凑指数）。

---

## 二、判定流程

1. **数步数**：1 步 → 基础；2–3 步 → 提高；≥4 步，或存在易错中间步 → 挑战。
2. **看技巧**：出现构造性技巧（第 D3 条所列）→ 直接定为挑战。
3. **看知识面**：跨两个以上知识点综合 → 升一档（最高到挑战）。
4. **取最高**：三条结论不一致时，按最高档定级。

补充约定：

- 概念辨析题（充要条件、性质判断）不算"背定义"，按**提高**处理——它考的是条件之间的区分，不是默写。
- 纯默写 / 辨认表述的题按**基础**处理。
- 计算量大但方法是唯一标准的题（如三阶行列式展开），最多定到**提高**。
