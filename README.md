# Lemma · 数分 / 高代 刷题站

一个纯前端刷题网站：**三本教材全部课后习题 + 练习，共 1387 题**，含难度分级、自动判分、详细解析、错题本。无需安装、无需服务器。

## 快速开始

**双击 `index.html`**（或拖进浏览器）即可使用，完全离线，无需安装、无需联网。

> ⚠️ 换电脑 / 发给别人时，请**整个 `刷题网站` 文件夹一起拷**（或压缩成 zip 再传）。
> 只拷 `index.html` 会显示「题目总数 0」——因为题库在 `data/`、公式引擎在 `assets/katex/`，缺一个都加载不出来。

## 功能

- **题集列表**：题号、题目名称、考点标签、难度色块（基础绿 / 提高黄 / 挑战红）、状态、通过率（仿洛谷题单排版）
- **考点标签**：按小节/关键词自动归类为「函数与映射、中值定理、偏导数与全微分、幂级数…」等 90 余个核心考点，不再显示「第N章」章节名
- **筛选**：搜索（题号/标题/题干）/ 难度 / 考点 / 状态 / **教材**（线代与几何、工科分析·上、工科分析·下、数分·高代练习）/ 来源（教材习题、练习）
- **详情页作答**（每道题都能作答，四种题型统一三卡布局：题目 → 作答区 → 结果）
  - 选择题：点选即判，正确项标绿、错选项标红
  - 填空题：支持 `2/3`、`0.5`、`π`、`π^2/6`、`e-1`、`√2`、`sqrt(2)`、`sin(π/6)`，也支持 `$\frac{1}{2}$` 这类 LaTeX 写法，数值容差 `1e-6`
  - 自评题 / 证明题：内置 **LaTeX 编辑器**——9 组约 100 个符号（分式根式 / 微积分 / 关系运算 / 函数 / 希腊字母 / 集合逻辑 / 矩阵排版 / 几何 / 大写希腊），按钮直接显示 KaTeX 渲染后的效果；点选后**公式直接作答框内渲染显示**（不是原始代码），点框内公式可弹出输入框改 LaTeX，普通文字照常输入；提交后对照参考答案与解析自评「答对了 / 没答对」
  - 草稿自动保存（刷新不丢），作答后可一键「下一题 →」连续刷
- **错题本**：任意题目可点「＋ 加入错题本」自由加入，答错自动进入，答对自动移出，也可在错题本里点「移出」手动删除
- **学习统计**：已练、正确率、错题数（存于 localStorage）
- **选项防猜**：选择题选项按题目 id 确定性打乱，避免正确项全在 A

```

├─ index.html                 # 页面骨架（结构 + 资源引用）

│  └─ json/                   # 分章源数据
│     ├─ ch1.json … ch9.json  # 线代各章
│     ├─ s1.json … s4.json    # 工科分析·上 第 1–4 章
│     └─ x5.json … x7.json    # 工科分析·下 第 5–7 章
```

## 重新生成题库

编辑 `source/json/` 下对应章节的 JSON 后，在项目根目录执行：

```bash
node tools/integrate.js            # 线代与几何 → data/book_questions.js
node tools/integrate_analysis.js   # 工科分析两册 → data/analysis1_questions.js / analysis2_questions.js
node tools/check_json.js           # 校验（JSON 可解析、题数、题型、坏题、重复 id）
```

`integrate.js` / `integrate_analysis.js` 会做类型规范化（非数值填空自动转为自评题）、校验（id 去重 / 答案合法性）、清理选择题题干里重复的内联选项，再写出对应的 JS 题库文件。三个脚本都用 `__dirname` 定位路径，在任何目录下执行都可以。

## 说明

- 题目解析按书末官方答案逐条核对；与官方一致者解析末尾标 `[✓官方]`。
- 少数题目书末答案与原题数据不自洽（线代如 ch2-6-5、ch3-32-3、ch4-5、ch5-1(3)；分析如 s3-3.4-B3、s4-zh-1、x5-5.3-35(1)、x6-ch-17 等），已在对应 `solution` 中注明「书末答案似有误」并保留推导结果，建议以题面为准。
- id 规则：
  - 线代 `ch{章}-{题号}-{小问}`，如 `ch1-1-1`
  - 工科分析·上 `s{章}-{节}-{题号}`，如 `s2-2.1-3`；章末习题 `s{章}-ch-n`；综合 `s{章}-zh-n`
  - 工科分析·下 `x{章}-{节}-{题号}`，如 `x5-5.1-2`
